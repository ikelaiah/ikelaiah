# Hi, I'm Iwan 👋

I build **practical developer tools**, mostly around **data, databases, documentation, and Free Pascal**.

I enjoy taking awkward and interesting  problems — complicated SQL, repetitive CLI plumbing, numerical routines, documentation that nobody wants to maintain — and turning them into tools that are easier to understand and use.

My interests include **Object Pascal / Free Pascal**, SQL, Python, R, developer tooling, data engineering, numerical computing, and pragmatic software design.

## Featured projects

### 🌱 [DocSprout](https://github.com/ikelaiah/docsprout)

**Grow polished documentation from Markdown.**

A documentation-site generator with search, themes, responsive navigation, GitHub Pages publishing, release history, and support for existing repositories.

---

### 🔀 [ProcFlow](https://github.com/ikelaiah/ProcFlow)

**Understand complicated SQL without tracing every branch by hand.**

A local browser-based SQL analysis and visualisation tool for control flow, dependencies, column lineage, ERDs, reports, and query construction.

Supports T-SQL, DB2 SQL PL, PostgreSQL PL/pgSQL, and SQLite.

---

### ⚡ [cli-fp](https://github.com/ikelaiah/cli-fp)

**Native command-line applications for Free Pascal.**

A reusable CLI framework with command trees, validation, generated help, shell completion, colours, spinners, progress indicators, and project generation.

---

### ∑ [mathlib-fp](https://github.com/ikelaiah/mathlib-fp)

**Practical mathematics for Free Pascal.**

Numerical, statistical, scientific, financial, engineering, and machine-learning tools with an emphasis on tested algorithms, documented limitations, and reproducible results.

---

### 🦆 [duckdb-fp](https://github.com/ikelaiah/duckdb-fp)

**DuckDB and DataFrame-style analysis for Free Pascal.**

Free Pascal bindings for DuckDB together with a higher-level interface for querying databases and working with CSV, Parquet, and tabular data.

---

### 🧵 [threadpool-fp](https://github.com/ikelaiah/threadpool-fp)

**Practical concurrency for Free Pascal.**

Thread pools, bounded producer-consumer queues, tasks, batches, cancellation, error handling, and coordination primitives for native Pascal applications.

## How I like to build

I tend to favour software that is:

- **Useful before clever**
- **Explicit about its limitations**
- **Easy to learn from examples**
- **Tested against real behaviour**
- **Small enough to understand**
- **Documented well enough that future-me does not curse present-me**

Most of my Pascal projects target **Free Pascal 3.2.2+** and Lazarus, with automated tests and runnable examples where practical.
